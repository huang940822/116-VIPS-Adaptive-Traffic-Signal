# Middleware Message Proxy (MMP) 

The MMP application handles the cloud package rx/tx as a middleware proxy.

---

## Cloud Package

MMP Service ID 0

**Compensation Strategy**
  * CMD 1：雲端變更控制策略

**VMS Strategy**
  * CMD 2：雲端更新 VMS 圖片
  * CMD 3：雲端更改 VMS 播放
  * CMD 4：雲端查詢 VMS 播放節目編號
  * CMD 5：雲端查詢 VMS 編號對應檔案名稱
